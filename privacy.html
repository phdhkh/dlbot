Privacy Policy for dlbot

Last updated: 27 October 2026.

What dlbot does

dlbot is a personal Telegram bot. When the user sends a video link, the bot downloads the video and uploads it to a folder in the user's own Google Drive.

What data is accessed

  • The links and messages the user sends to the bot on Telegram.
  • The user's Google Drive, only to upload files the user asked the bot to upload, into the folder the user chose.

What is NOT done with your data

Data is not sold, shared with third parties, or used for advertising. The bot runs on the user's own server, and the Google authorization token is stored only on that server.

How to revoke access

The user can revoke dlbot's access at any time from their Google Account: Security > Third-party access > dlbot > Remove access.
